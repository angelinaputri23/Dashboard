# Store Operations Dashboard

Single GitHub Pages portal for:
- Store Sales Performance
- Redeemed Points Dashboard
- Store Stock & Promo Planning

## Publish
1. Create a new GitHub repository named `Store-Operations-Dashboard`.
2. Upload the **contents** of this folder to the repository root (not an extra nested folder).
3. Open Settings → Pages.
4. Select Deploy from a branch, branch `main`, folder `/(root)`, then Save.
5. Open `https://YOUR-USERNAME.github.io/Store-Operations-Dashboard/`.

The three subfolders contain temporary placeholder pages. Dashboard features and Google Sheets integration are the next stage.

## Privacy
Never expose raw member names, emails, phone numbers, or Member IDs on a public GitHub Pages website. Publish aggregated, non-identifying data only.
